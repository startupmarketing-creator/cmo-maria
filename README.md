# cmo-maria

Личный сайт Марии Артемьевой — CMO-консультанта.

**Сайт:** [cmo-maria.com](https://cmo-maria.com)

## Как устроено

Статичный сайт без фреймворков и сборщиков. Контент хранится в `site.json` и синхронизируется из Notion через GitHub Actions. `app.js` читает этот файл и строит страницу на лету.

Навигация между страницами работает через hash-роутинг (`/#about` и т.д.) — без перезагрузки.

## Файлы

| Файл | Назначение |
|------|-----------|
| `index.html` | Оболочка страницы |
| `app.js` | Рендерер контента |
| `style.css` | Стили |
| `site.json` | Контент, навигация, настройки (из Notion) |
| `CNAME` | Кастомный домен для GitHub Pages |

## Запуск локально

```bash
npx serve .
```

Затем открыть [http://localhost:3000](http://localhost:3000).
